# Decisions

One file per decision: `NNNN-slug.md`. `NNNN` is the next free integer,
four digits, and it is not reused. Add a new file. Do not append a numbered
list to `PROGRESS.md`, and do not edit an older file to record a new
decision.

`PROGRESS.md` is current state: phase, pins, status, level gates, tracking,
blocked items, and judge disputes. A decision that outlives a single issue
is a new file in this directory.

The files are the index. There is no second list to update.
