# Day 0

The first commit on `main` is "Day 0: mission and guardrails." Placeholder pages, the README, and the Kite site ([#124](https://github.com/Zouhairmaj/megabase/pull/124), [#125](https://github.com/Zouhairmaj/megabase/pull/125), [#126](https://github.com/Zouhairmaj/megabase/pull/126)) were already on that line when [pull request #1](https://github.com/Zouhairmaj/megabase/pull/1) merged. That pull request brought the Phase 0 bootstrap: a Cargo workspace, the pinned `vendor/` submodules, a gateway that returns HTTP 501, the coverage extractor, the Judge, the 3×3 tile mark, the green and neutral palette, a JetBrains Mono wordmark, and committee-reviewed `AGENTS.md`.

[`v0.1.0`](https://github.com/Zouhairmaj/megabase/releases/tag/v0.1.0) was published at 18:27 UTC. It includes JWT validation, a treemap sized for 1,024 units, and the MFA, OAuth, one-time, and refresh tables in `e708e9c`.

After that tag, Auth gained SQL functions and tables, SAML, SSO, and SCIM users and sessions, and WebAuthn challenge and credential tables. The first admin get and delete routes merged ([#151](https://github.com/Zouhairmaj/megabase/pull/151)). Short JWT secrets are rejected ([#170](https://github.com/Zouhairmaj/megabase/pull/170)). The Judge gained database side-effect checks ([#149](https://github.com/Zouhairmaj/megabase/pull/149)) and Auth admin cases ([#152](https://github.com/Zouhairmaj/megabase/pull/152)). CI added release-artifact signing ([#160](https://github.com/Zouhairmaj/megabase/pull/160)) and cargo-fuzz targets ([#158](https://github.com/Zouhairmaj/megabase/pull/158)).

The last commit of the day, `c24c54d`, records 4.1% coverage in `coverage/summary.json`: 42 of 1,024 units implemented, 40 tested. The committed Judge baseline in that file is 87 cases, none marked passing. `coverage/judge-history.json` on `gh-pages` has no run for a 9 October commit.

`HUMAN_LOG.md` records three completed actions. GitHub Actions may create and approve pull requests. A read-only `SCORECARD_TOKEN` was added so Scorecard can read branch protection. Docker Hub credentials were added after unauthenticated pulls returned HTTP 429. Two items dated this day stay pending in that log: `RELEASE_PLEASE_TOKEN`, and a dispatch from tag `v0.1.0` so that release gains signed binaries.
