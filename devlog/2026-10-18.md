# Deno.memoryUsage() lands and coverage reaches 33%

Two pull requests merged. Edge Functions now serves `Deno.memoryUsage()` the way an edge-runtime user worker does, and the 16 October log landed. Coverage went from 32.9% to 33.0%. The Judge suite stayed at 447 cases. This log uses Africa/Casablanca (UTC+1). Both merges are on 18 October in UTC as well.

[#479](https://github.com/Zouhairmaj/megabase/pull/479) serves `functions:op:op_runtime_memory_usage`. `Deno.memoryUsage()` returns `{ rss: 0, heapTotal, heapUsed, external }`, keeping Deno's heap numbers, as `ext/runtime/lib.rs:339` does. The runtime spec's second slice (issue #77) lists ten ops. This is the one that is served and marked. The other nine stay unserved; each row in `specs/functions/runtime.md` records why. No Judge case was added. The vendored `hello` function does not call `Deno.memoryUsage()`.

The 16 October log ([#481](https://github.com/Zouhairmaj/megabase/pull/481), closes #480) merged late on the 18th. That entry uses UTC dates.
