# Realtime opens its WebSocket and coverage passes 30%

Level 2 and Level 3 work moved fast. Realtime went from one served unit to all 19, Storage answered its S3, iceberg and vector routes as the reference stack does, and Auth served OAuth provider redirects for 20 built-in providers. Coverage went from 22.8% to 32.9%, and the Judge suite grew from 410 cases to 447. This log uses UTC dates. Five merges landed after the 15 October log was written but before midnight UTC, so they belong to 15 October: SMS and `phone_change` verify ([#421](https://github.com/Zouhairmaj/megabase/pull/421)), batch signed URLs and signed upload URLs ([#417](https://github.com/Zouhairmaj/megabase/pull/417)), the 15 October log itself ([#425](https://github.com/Zouhairmaj/megabase/pull/425)), and releases [0.1.38](https://github.com/Zouhairmaj/megabase/pull/422) and [0.1.39](https://github.com/Zouhairmaj/megabase/pull/427).

Realtime now serves the Phoenix socket that supabase-js opens:

- [#457](https://github.com/Zouhairmaj/megabase/pull/457) serves the `GET /realtime/v1/websocket` handshake, heartbeat, join and leave, with upstream's connect errors and join reply reasons.
- [#458](https://github.com/Zouhairmaj/megabase/pull/458) adds broadcast and presence on public channels.
- [#466](https://github.com/Zouhairmaj/megabase/pull/466) serves the HTTP broadcast API, batch and single-event (closes #67).
- [#468](https://github.com/Zouhairmaj/megabase/pull/468) serves `access_token` refresh and channel token expiry, and marks the `phx_*` protocol events (closes #68).
- [#469](https://github.com/Zouhairmaj/megabase/pull/469) decodes V2 binary frames, so broadcasts sent by realtime-js 2.x reach the other sockets (closes #66).
- [#470](https://github.com/Zouhairmaj/megabase/pull/470) serves the broadcast, disconnect and system server events, including the joins-per-second rate limit. [#471](https://github.com/Zouhairmaj/megabase/pull/471) serves `postgres_changes`: startup installs the tenant CDC objects, and a poller reads changes from a temporary wal2json slot (closes #69).

Storage answers what the self-hosted reference stack answers:

- The S3 protocol routes are registered there, and supported unsigned request forms get `AccessDenied` / `Missing signature` before any command runs. Other unsigned forms stay 501, and an unsigned POST policy form gets `InvalidSignature`. [#444](https://github.com/Zouhairmaj/megabase/pull/444), [#445](https://github.com/Zouhairmaj/megabase/pull/445) and [#450](https://github.com/Zouhairmaj/megabase/pull/450) serve GET and DELETE, HEAD and POST (including the POST policy form), then PUT. Signed requests stay 501.
- The iceberg ([#442](https://github.com/Zouhairmaj/megabase/pull/442)) and vector ([#448](https://github.com/Zouhairmaj/megabase/pull/448)) routes answer the 404 of a plugin that is not enabled.
- [#456](https://github.com/Zouhairmaj/megabase/pull/456) serves bucket delete and empty and object move and copy (closes #455).
- Signed object GET honours `download` and maps malformed tokens to `InvalidJWT` ([#463](https://github.com/Zouhairmaj/megabase/pull/463), closes #460).

Auth changes:

- [#424](https://github.com/Zouhairmaj/megabase/pull/424) gates the OAuth 2.1 server routes behind their disabled check and serves dynamic client registration and userinfo.
- `GET /authorize` builds the provider redirect for 20 built-in providers: eight in [#426](https://github.com/Zouhairmaj/megabase/pull/426), eight more in [#432](https://github.com/Zouhairmaj/megabase/pull/432) (closes #431), and twitch, workos, x and zoom in [#434](https://github.com/Zouhairmaj/megabase/pull/434) (closes #433). Providers whose setup fetches OIDC discovery stay 501.
- Every `/passkeys` route is gated, and passkey list, rename and delete are served ([#435](https://github.com/Zouhairmaj/megabase/pull/435), closes #50). Registration and sign-in stay 501.
- The three SCIM discovery routes are served behind their dark-shipped gate ([#437](https://github.com/Zouhairmaj/megabase/pull/437), closes #51).
- The SSO routes are gated behind the SAML disabled check ([#439](https://github.com/Zouhairmaj/megabase/pull/439)).

Edge Functions changes:

- Response bodies are dropped for HEAD, null-body and redirect statuses, as edge-runtime does ([#473](https://github.com/Zouhairmaj/megabase/pull/473), closes #74).
- The user-worker `Deno.env` is served: Megabase-only variables are hidden, `SB_EXECUTION_ID` is added, and `set` is not supported ([#474](https://github.com/Zouhairmaj/megabase/pull/474), closes #72).
- [#478](https://github.com/Zouhairmaj/megabase/pull/478) writes the runtime ops spec and makes `Deno.consoleSize()` return 80×24. It adds no unit markers, because those ops have no counterpart in a plain Deno process.
- [#477](https://github.com/Zouhairmaj/megabase/pull/477) records a Judge dispute in `PROGRESS.md`: a `Deno.env` case needs a function that reads it, and the only vendored function does not. A human needs to decide whether a judge-only function may be mounted (closes #476).

Judge cases and CI:

- Auth cases cover the passkeys disabled gate on all seven routes ([#436](https://github.com/Zouhairmaj/megabase/pull/436)) and the SCIM disabled gate ([#438](https://github.com/Zouhairmaj/megabase/pull/438)).
- Storage cases cover the 26 unsigned S3 units, plus a check that a Supabase bearer token is not a SigV4 signature ([#452](https://github.com/Zouhairmaj/megabase/pull/452), closes #451).
- [#454](https://github.com/Zouhairmaj/megabase/pull/454) installs Deno and enables functions for the Megabase side of the Judge, so the functions cases can pass (closes #453).
- [#429](https://github.com/Zouhairmaj/megabase/pull/429) prepares the Megabase database in the lockfile Judge job, which had timed out on release 0.1.39 (closes #428).
- [#440](https://github.com/Zouhairmaj/megabase/pull/440) regenerates generated files that were stale after the SCIM cases merged, and [#447](https://github.com/Zouhairmaj/megabase/pull/447) syncs `Cargo.lock` after 0.1.42 (closes #446).

Nine release PRs merged: [0.1.40](https://github.com/Zouhairmaj/megabase/pull/430), [0.1.41](https://github.com/Zouhairmaj/megabase/pull/441), [0.1.42](https://github.com/Zouhairmaj/megabase/pull/443), [0.1.43](https://github.com/Zouhairmaj/megabase/pull/449), [0.1.44](https://github.com/Zouhairmaj/megabase/pull/459), [0.1.45](https://github.com/Zouhairmaj/megabase/pull/465), [0.1.46](https://github.com/Zouhairmaj/megabase/pull/467), [0.1.47](https://github.com/Zouhairmaj/megabase/pull/472) and [0.1.48](https://github.com/Zouhairmaj/megabase/pull/475).
