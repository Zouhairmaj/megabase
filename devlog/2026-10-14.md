# Judge cases pass 380 and the reference Postgres moves to ghcr.io

Most of the day's work went to Level 1 (REST and Auth email/password). The Judge suite grew from 230 cases on 13 October to 383, and coverage went from 16.5% to 16.8%.

REST behavior changed in several PRs. Embeds gained inner and left joins for #24 ([#294](https://github.com/Zouhairmaj/megabase/pull/294)). They now resolve FK column and constraint targets, and an ambiguous embed returns PGRST201 ([#341](https://github.com/Zouhairmaj/megabase/pull/341)). Aggregates follow the aggregates-enabled setting ([#292](https://github.com/Zouhairmaj/megabase/pull/292)). Media-type negotiation also changed. The plan media type returns 406 while plans are disabled ([#314](https://github.com/Zouhairmaj/megabase/pull/314)). `vnd.pgrst.object+json` is served on writes and RPC ([#326](https://github.com/Zouhairmaj/megabase/pull/326)), and `application/geo+json` and `application/octet-stream` are served too ([#328](https://github.com/Zouhairmaj/megabase/pull/328)). CORS headers are now complete on preflight and simple requests ([#325](https://github.com/Zouhairmaj/megabase/pull/325)). The JWT and query-parameter denial bodies match PostgREST ([#343](https://github.com/Zouhairmaj/megabase/pull/343)), and so do the OpenAPI document and the 403 on `GET /rest/v1/` ([#342](https://github.com/Zouhairmaj/megabase/pull/342)).

Auth now reads null request fields as absent, as the Go server does ([#322](https://github.com/Zouhairmaj/megabase/pull/322), [decision 0037](https://github.com/Zouhairmaj/megabase/blob/main/docs/decisions/0037-auth-null-request-fields.md)). The gateway answers Kong CORS preflights ([#323](https://github.com/Zouhairmaj/megabase/pull/323)). [#332](https://github.com/Zouhairmaj/megabase/pull/332) makes `bad_json` messages identical to Go's, including case-insensitive field matching. It also adds a rate limit on the password grant. [#345](https://github.com/Zouhairmaj/megabase/pull/345) runs the pg-functions `custom_access_token` hook when a token is issued. [#351](https://github.com/Zouhairmaj/megabase/pull/351) grants `postgres` and `dashboard_user` ALL on the auth tables, as the Supabase Postgres image does. It also keeps the varchar default expressions on `users.phone` and `users.phone_change`. Startup now creates `anon`, `authenticated`, `service_role` and `authenticator` when they are missing, and it never alters roles that already exist ([#324](https://github.com/Zouhairmaj/megabase/pull/324), [decision 0037](https://github.com/Zouhairmaj/megabase/blob/main/docs/decisions/0037-bootstrap-standard-roles.md)).

Judge cases and harness changes:

- REST cases cover resources routes ([#290](https://github.com/Zouhairmaj/megabase/pull/290)), RPC routes ([#291](https://github.com/Zouhairmaj/megabase/pull/291)), logic operators ([#298](https://github.com/Zouhairmaj/megabase/pull/298)), order modifiers ([#299](https://github.com/Zouhairmaj/megabase/pull/299)) and `Prefer` ([#301](https://github.com/Zouhairmaj/megabase/pull/301)). They also cover media types ([#311](https://github.com/Zouhairmaj/megabase/pull/311), [#312](https://github.com/Zouhairmaj/megabase/pull/312), [#313](https://github.com/Zouhairmaj/megabase/pull/313)).
- Auth cases cover webauthn tables ([#293](https://github.com/Zouhairmaj/megabase/pull/293)) and admin endpoints ([#304](https://github.com/Zouhairmaj/megabase/pull/304)). [#340](https://github.com/Zouhairmaj/megabase/pull/340) raises the Level 1 auth case minimum with refresh_token, health, settings and logout cases.
- The Judge treats `request_id` as volatile ([#344](https://github.com/Zouhairmaj/megabase/pull/344)). It applies Supabase default privileges before it loads fixtures ([#346](https://github.com/Zouhairmaj/megabase/pull/346)).
- [#329](https://github.com/Zouhairmaj/megabase/pull/329) adds a supabase-js real-app smoke test (`realapp.yml`, decision 0038). It runs the 24-step scenario from #320 with `@supabase/supabase-js` 2.117.3. A failure does not fail the check yet.

[#353](https://github.com/Zouhairmaj/megabase/pull/353) adds a workflow that mirrors `public.ecr.aws/supabase/postgres` to `ghcr.io/zouhairmaj/supabase-postgres`, keeping the same tag and digest. The Judge compose overlay now uses the mirror by default. `.github/actions/judge-db-image` falls back to ECR when the mirror cannot be pulled. Judge, held-out Judge, the lockfile Judge job and Real app all use this path (decision 0039, closes #350).

Two PRs work on signed release artifacts for old tags. [#303](https://github.com/Zouhairmaj/megabase/pull/303) allows a release backfill to run from main. Backfilling v0.1.0 then failed in both build jobs, because the tag predates `.github/actions/sccache`. [#352](https://github.com/Zouhairmaj/megabase/pull/352) fixes this: a backfill now loads the local actions from the run commit and checks out the tag for the build itself (closes #305). The backfill run itself is not in the git history.

Agent workflows can now choose a model by label: `model:fable` selects Fable 5.1 ([#315](https://github.com/Zouhairmaj/megabase/pull/315)) and `model:opus` selects Opus ([#335](https://github.com/Zouhairmaj/megabase/pull/335)). The #315 commit records Zouhair's chat approval for the protected workflow change.

Six release PRs merged: [0.1.22](https://github.com/Zouhairmaj/megabase/pull/297), [0.1.23](https://github.com/Zouhairmaj/megabase/pull/300), [0.1.24](https://github.com/Zouhairmaj/megabase/pull/327), [0.1.25](https://github.com/Zouhairmaj/megabase/pull/330), [0.1.26](https://github.com/Zouhairmaj/megabase/pull/334) and [0.1.27](https://github.com/Zouhairmaj/megabase/pull/347).
