# Claude pushes now start CI

Pushes made with `GITHUB_TOKEN` do not start workflows, so CI and the Judge never ran on Claude's pull requests ([#273](https://github.com/Zouhairmaj/megabase/pull/273), [#279](https://github.com/Zouhairmaj/megabase/pull/279), [#282](https://github.com/Zouhairmaj/megabase/pull/282), [#283](https://github.com/Zouhairmaj/megabase/pull/283)). [#286](https://github.com/Zouhairmaj/megabase/pull/286) changes `.github/workflows/claude.yml` to push and open PRs with the first available of `MEGABASE_AGENT_GH_TOKEN`, `RELEASE_PLEASE_CLASSIC_TOKEN` (the megabase-agent classic PAT) and `GITHUB_TOKEN`. The workflow comment says `MEGABASE_AGENT_GH_TOKEN` was not an Actions secret, so the old chain had fallen through to `GITHUB_TOKEN`. Zouhair approved the change in chat. #286 replaced [#284](https://github.com/Zouhairmaj/megabase/pull/284) because workflow changes need a `review/*` branch, and it was admin-merged as `ac47a27` with all checks green but no code-owner review. `HUMAN_LOG.md` records the approval.

Auth gained two request-validation changes. [#279](https://github.com/Zouhairmaj/megabase/pull/279) validates recover requests and hides unknown emails. [#285](https://github.com/Zouhairmaj/megabase/pull/285) validates resend requests before the mailer 501. REST now serves `application/x-www-form-urlencoded` request bodies ([#283](https://github.com/Zouhairmaj/megabase/pull/283)).

Judge cases landed in three test PRs: return, timezone, and transaction cases for #39 ([#273](https://github.com/Zouhairmaj/megabase/pull/273)), filter-operator cases for #26 ([#288](https://github.com/Zouhairmaj/megabase/pull/288)), and aggregate cases for #22 ([#289](https://github.com/Zouhairmaj/megabase/pull/289)). [#282](https://github.com/Zouhairmaj/megabase/pull/282) synced `Cargo.lock` after 0.1.19.

Two release PRs merged: [0.1.20](https://github.com/Zouhairmaj/megabase/pull/280) and [0.1.21](https://github.com/Zouhairmaj/megabase/pull/287).
