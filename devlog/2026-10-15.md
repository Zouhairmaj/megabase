# Storage objects, Edge Functions and PKCE land in one day

Work spread beyond Level 1 for the first time. Storage gained buckets, objects and listing, Edge Functions started running, and Auth completed the PKCE flow. Coverage went from 16.8% to 22.4%, and the Judge suite grew from 383 cases to 410. This log uses UTC dates; the 14 October log ([#356](https://github.com/Zouhairmaj/megabase/pull/356)) and release [0.1.28](https://github.com/Zouhairmaj/megabase/pull/357) merged just before midnight UTC and belong to 14 October.

[#354](https://github.com/Zouhairmaj/megabase/pull/354) fixes a batch of Level 1 Judge differences (closes #349). The gateway answers Kong's key-auth 401 "No API key found in request" on the Auth, REST, GraphQL, Realtime and Meta routes, and leaves Kong's open Auth routes alone. Auth `/health` and `/settings` answer other methods with chi's empty 405, and `GET /authorize` rejects unknown providers with GoTrue's 400. Meta serves `GET /pg/health` and `/pg/config/version`, Realtime serves `GET /api/ping`, and Storage lists buckets for the service role. The `auth.settings` Judge mismatch is recorded as a blocker in `PROGRESS.md`.

Storage moved from a stub to a working object store under storage-api's RLS request scope:

- `GET /storage/v1/health` ([#361](https://github.com/Zouhairmaj/megabase/pull/361)), bucket create, update and lifecycle routes ([#362](https://github.com/Zouhairmaj/megabase/pull/362)) and the CDN purge routes ([#363](https://github.com/Zouhairmaj/megabase/pull/363), closes #57).
- [#366](https://github.com/Zouhairmaj/megabase/pull/366) installs the v1.80.2 operation helpers, bucket triggers and `storage.extension()`, drops the prefix functions that the pinned migrations removed, and runs the install in one transaction under an advisory lock.
- Render image routes answer storage-api's errors up to the renderer; reaching the renderer stays 501 ([#367](https://github.com/Zouhairmaj/megabase/pull/367), closes #62).
- [#392](https://github.com/Zouhairmaj/megabase/pull/392) serves object upload, download, sign and remove, installs `storage.objects` in its final migration shape, and stores bytes under `FILE_STORAGE_BACKEND_PATH`. Uploads also accept `multipart/form-data` ([#403](https://github.com/Zouhairmaj/megabase/pull/403), closes #398).
- `POST /object/list/{bucket}` runs through the ported `storage.search()` ([#405](https://github.com/Zouhairmaj/megabase/pull/405)). Single object delete, object info and authenticated HEAD follow in [#416](https://github.com/Zouhairmaj/megabase/pull/416).
- [#419](https://github.com/Zouhairmaj/megabase/pull/419) writes the resumable upload spec. Every `/upload/resumable` route depends on `@tus/server`, which is not vendored, so the 16 routes stay 501 and the blocker is listed in `PROGRESS.md`.

Edge Functions run. [#394](https://github.com/Zouhairmaj/megabase/pull/394) serves `/functions/v1/{name}` by running each function as a `deno run` child process on a loopback port, with edge-runtime's `VERIFY_JWT` gate and error answers (closes #381, [decision 0042](https://github.com/Zouhairmaj/megabase/blob/main/docs/decisions/0042-functions-deno-child-process.md)). [#404](https://github.com/Zouhairmaj/megabase/pull/404) preloads a bootstrap so `std` `serve()` and `Deno.listen` servers bind the worker port instead of `:8000` ([decision 0043](https://github.com/Zouhairmaj/megabase/blob/main/docs/decisions/0043-functions-listen-bootstrap.md)).

REST embeds went further. They work through views by inheriting the foreign keys of the tables a view selects ([#385](https://github.com/Zouhairmaj/megabase/pull/385)). `!constraint` and `!column` hints pick one key, and an unhinted target with several keys returns PGRST201 ([#384](https://github.com/Zouhairmaj/megabase/pull/384), closes #376). Filters, order, limit and null filters apply to embedded resources ([#386](https://github.com/Zouhairmaj/megabase/pull/386)), and embeds nest at any depth, including self-references ([#389](https://github.com/Zouhairmaj/megabase/pull/389), closes #378). [#390](https://github.com/Zouhairmaj/megabase/pull/390) serves JSON-path filters. The gateway now percent-encodes raw quote, `<` and `>` bytes in the request line, which hyper used to reject with an empty 400 before any router ran.

Auth changes:

- `/callback` serves its state and error redirects, and `/magiclink` and `/otp` port their validation ([#373](https://github.com/Zouhairmaj/megabase/pull/373)).
- MFA route gates, factor unenroll, and recovery-code status and delete are served; enrollment, challenges and verification stay 501 ([#374](https://github.com/Zouhairmaj/megabase/pull/374)).
- `POST /recover` sends password recovery through the no-op mail client, or answers 500 when the SMTP host cannot be reached, as the reference stack does ([#391](https://github.com/Zouhairmaj/megabase/pull/391), closes #382).
- `POST /invite` serves the admin `inviteUserByEmail` ([#412](https://github.com/Zouhairmaj/megabase/pull/412), closes #401).
- [#406](https://github.com/Zouhairmaj/megabase/pull/406) ports the `pkce`, `id_token` and `web3` token grants. A PKCE code can now be obtained from recovery, magic link and signup confirmation links and redeemed with `grant_type=pkce`. Email signup with autoconfirm off, which was 501, now sends the confirmation. An enabled `id_token` provider or `web3` chain stays 501.
- [#420](https://github.com/Zouhairmaj/megabase/pull/420) serves the JWKS, OpenID configuration and OAuth authorization-server discovery documents.

Platform setup: startup bootstraps the `extensions`, `supabase_functions` and `vault` schemas and the `supabase_realtime` publication ([#388](https://github.com/Zouhairmaj/megabase/pull/388), closes #383). [#410](https://github.com/Zouhairmaj/megabase/pull/410) creates the `vault` schema even without `supabase_vault`, logs the mail and storage setup, and documents a standalone environment in `docs/configuration.md` ([decision 0044](https://github.com/Zouhairmaj/megabase/blob/main/docs/decisions/0044-unset-smtp-host-follows-reference.md)).

Judge cases and harness changes:

- Storage cases cover bucket create, update and lifecycle ([#365](https://github.com/Zouhairmaj/megabase/pull/365)) and render image errors ([#369](https://github.com/Zouhairmaj/megabase/pull/369)).
- Functions cases cover invocation and `VERIFY_JWT` ([#396](https://github.com/Zouhairmaj/megabase/pull/396)); `megabase-functions` now maps to the Judge (functions) shard. [#408](https://github.com/Zouhairmaj/megabase/pull/408) regenerates coverage to count them.
- Auth cases cover `POST /invite` ([#414](https://github.com/Zouhairmaj/megabase/pull/414)).
- The ghcr.io mirror from #353 now covers every reference image. [#359](https://github.com/Zouhairmaj/megabase/pull/359) adds the Dockerfile bases and Kong, with an ECR and then Docker Hub fallback under one shared retry limit ([decision 0040](https://github.com/Zouhairmaj/megabase/blob/main/docs/decisions/0040-ghcr-library-image-mirrors.md)). [#372](https://github.com/Zouhairmaj/megabase/pull/372) adds studio, gotrue, realtime, storage-api, postgres-meta, edge-runtime and supavisor ([decision 0041](https://github.com/Zouhairmaj/megabase/blob/main/docs/decisions/0041-ghcr-supabase-image-mirrors.md)).
